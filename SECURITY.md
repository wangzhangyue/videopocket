# Security

This is experimental software; there is no guaranteed support or response time. Use the latest reviewed source and supported upstream dependencies.

Do not post credentials, cookies, signed URLs, local paths, personal videos, or exploit details in public issues. If GitHub's private vulnerability reporting is enabled, use Security → Report a vulnerability. If that option is unavailable, open a minimal issue requesting a private contact channel without disclosing the vulnerability; wait for the maintainer to provide one.

The helper validates extension origin, command fields, file identity and output paths. It passes arguments without invoking a shell for media jobs. These controls are not a security audit or a guarantee that external media parsers are safe. Do not disable macOS protections to run an untrusted installer.
