VideoPocket 0.2.2 · 内测版

拾影连接浏览器与 Mac。下载、合并和文件校验，都由本地助手完成。

安装，只需一次

  1. 解压内测发行包，在 Chrome 打开 chrome://extensions，开启「开发者模式」，点击「加载已解压的扩展程序」，选择 extension 文件夹。
  2. 双击同一发行包里的 与你的芯片匹配的安装器：Intel 选 VideoPocket-0.2.2-x64.pkg，Apple M 系列选 VideoPocket-0.2.2-arm64.pkg，按照 macOS 安装器提示完成安装。
  3. 打开网站视频页，点击拾影。连接正常时直接显示下载界面；连接异常时会出现提示和「重新检测」。
  4. 默认保存到「下载 / 拾影」。点击「更改」可使用系统目录选择器选一个新位置。

系统要求：macOS 13+、Chrome 桌面版。提供 Intel 与 Apple Silicon 两种安装包；如提示「不能安装在这台电脑上」，请在「关于本机」查看芯片并核对版本。本内测包尚未做 Developer ID 签名与公证；系统可能阻止安装。请核对来源后按 macOS「隐私与安全性」提示允许此次安装，无需关闭系统安全功能。

开始保存

打开公开的网站点播视频，点击插件后会读取当前链接并解析。也可以粘贴链接，选择清晰度，点击「下载到本地」。支持多个网站、视频直链及 HLS/DASH 点播，最高 1080p。页面解析失败时，可尝试视频原页面或有效的媒体链接。未知清晰度可尝试原始格式；缺少声音、画面或超过 1080p 的文件不会标记成功。

视频、音频分别显示进度，之后显示「正在合并」和「正在校验文件」。出现「已保存」后，点击「在文件夹中显示」。关闭弹窗或视频标签页不影响任务；退出 Chrome 会中断任务，下次打开可从头重试。

在右上角选择「中文」或「English」。插件会记住语言，并与帮助页同步。切换不会重启下载或修改文件名；系统对话框及原始诊断日志不随插件语言切换。

连接与下载故障

需要安装本地助手
确认已运行发行包内的安装器，然后重新检测。仅加载 Chrome 插件不会自动安装助手。
助手未正确配对 / 无法启动
重新安装同一版本的插件与助手，保留原始 extension 文件夹里的 manifest.json。若系统阻止程序运行，按系统提示处理。只支持正式版 Google Chrome。
组件启动超时
安装后的首次检测可能需要约 45 秒。超时不代表文件缺失，请等待片刻后重新检测；仍失败时展开诊断信息。
版本不兼容 / 组件缺失
用配套的完整安装包覆盖安装助手。助手包含 Node、yt-dlp（含 EJS）、FFmpeg 与 FFprobe，无需自己逐个安装。
需要登录、平台验证或无法访问
先确认原视频页面是否能访问。首版不导入 Cookie，不支持需要登录、验证、付费或 DRM 的内容。部分公开视频也可能被平台要求验证。
能播放但无法解析
blob 只是播放器的临时地址，不能直接下载。跨域嵌入播放器请打开其原页面。DRM 或需要登录凭据的视频仍不支持，无法保证所有能播放的视频都能下载。
媒体地址过期
临时媒体链接可能过期，请重新解析视频原页面，或提供新的有效链接。
网络中断 / 合并失败
检查网络与磁盘空间后重试。重试会重新解析，并从头下载。可展开插件内的诊断信息排查。
无法保存到此位置
点击「更改」重新选择可写的本地目录。检查 macOS 的文件与文件夹访问权限；无需授予整个磁盘访问权限。
另一个 Chrome 配置正在使用助手
首版只允许本机当前用户同时连接一个 Chrome 配置。关闭另一配置的 Chrome 窗口、退出其后台进程后重试。
文件不存在
文件可能被移动、删除或替换。记录会保留，但不会再提供错误的文件定位。

助手与手动更新

当前配套版本 0.2.2。组件检测结果显示在插件连接状态中。

新版安装包由内测负责人随版本发布提供。收到新版后退出 Chrome，双击新版 .pkg 覆盖安装，将新包 extension 内的文件覆盖到原先加载的扩展文件夹，再打开 chrome://extensions 点击拾影卡片的刷新按钮并重新检测。插件与助手都需更新到 0.2.2。更新不会删除视频或最近任务。缩略图功能需安装新版 0.2.2 助手。历史记录保留；旧视频不会自动补图。

当前尚未配置公开下载地址，本页是内测安装与更新入口；请使用与你收到的插件同一发行包中的安装器。版本发布前应由维护者补充可访问的发行地址。

卸载

在 chrome://extensions 移除拾影。退出 Chrome 后，双击发行包里的「卸载拾影助手.app」，按提示卸载。

卸载器只移除助手和 Chrome 连接注册，保留所有视频和本地记录。如要清除记录，可先在插件点击「清空记录」，或在 Finder「前往文件夹」打开 ~/Library/Application Support/VideoPocket 后删除该文件夹。

本地与隐私

无账号、无视频中转服务器。只有主动打开插件或点击「使用当前页面」时读取当前链接。不读取 Cookie，不持续监听浏览行为。最近 20 条任务、保存目录和经过脱敏的错误信息存储在本机。

下载由本机直接连接目标网站及其媒体服务，必要时携带媒体所在页面的来源地址。选中的下载链接和来源地址随任务记录保存在本机，可能含临时访问参数。请仅下载自有或已获授权的内容。

VideoPocket 0.2.2 · Private beta

VideoPocket connects your browser to your Mac. The local helper downloads, merges and verifies your videos.

Install once

  1. Extract the release archive. Open chrome://extensions in Chrome, enable Developer mode, click “Load unpacked” and select the extension folder.
  2. Run the installer for your Mac: VideoPocket-0.2.2-x64.pkg for Intel, or VideoPocket-0.2.2-arm64.pkg for Apple M-series chips. Follow the macOS installer.
  3. Open a video page and open VideoPocket. A successful connection takes you straight to the download view. If the connection fails, an error and “Reconnect” appear.
  4. The default folder is Downloads / 拾影. Select “Change” to choose another folder using the system folder picker.

Requires macOS 13+ and desktop Chrome. Intel and Apple Silicon installers are provided. If macOS says the package cannot be installed on this computer, check your chip in “About This Mac” and choose the matching installer. This beta is not Developer ID signed or notarized. After verifying its source, follow the macOS Privacy & Security prompt to allow this installation. You do not need to disable system security.

Save a video

Open a public, on-demand video and open the extension to analyze its URL. You can also paste a link, select a quality and click “Download video”. Multiple sites, direct media URLs and HLS/DASH on-demand video are supported, up to 1080p. If analysis fails, try the original video page or a valid media URL. You can try the original format when its resolution is unknown. Files without both audio and video, or above 1080p, will not be marked successful.

Video and audio progress are shown separately, followed by merging and verification. Once saved, select “Show in Finder”. Closing the popup or video tab does not interrupt the task. Exiting Chrome interrupts it; you can retry from the start the next time you open the extension.

Choose 中文 or English in the top-right language menu. The extension remembers your choice and shares it with this help page. Switching language does not restart downloads or rename files. System dialogs and original diagnostics do not change with the extension language.

Connection & download problems

Install the local helper
Run the installer included in the release, then reconnect. Loading the Chrome extension alone does not install the helper.
Helper pairing or startup failed
Reinstall matching versions of the extension and helper. Keep the original manifest.json in the extension folder. If macOS blocks the program, follow its system prompt. Only the stable Google Chrome release is supported.
Component startup timed out
The first check after installation may take about 45 seconds. A timeout does not mean files are missing. Wait briefly and reconnect; if it still fails, open diagnostics.
Version mismatch or missing components
Reinstall the helper from the matching full release. It includes Node, yt-dlp with EJS, FFmpeg and FFprobe. You do not need to install them separately.
Sign-in, verification or access required
Check whether the video is accessible on its original page. This version does not import cookies or support content requiring sign-in, verification, payment or DRM. Platforms may also require verification for public videos.
The video plays but cannot be analyzed
A blob URL is a temporary player address and cannot be downloaded directly. For a cross-site embedded player, open the original player page. Videos requiring DRM or login credentials are not supported. Not every playable video can be downloaded.
Media URL expired
Media URLs can expire. Analyze the original video page again or provide a new valid URL.
Network interrupted or merging failed
Check your connection and free disk space, then retry. Retrying analyzes the link again and starts downloading from scratch. Expand diagnostics for details.
Cannot save to this folder
Select “Change” and choose a writable local folder. Check macOS Files and Folders permissions. Full Disk Access is not required.
Another Chrome profile is using the helper
This version allows one Chrome profile per local user to connect at a time. Close the other profile’s Chrome windows and background processes, then retry.
File not found
The file may have been moved, deleted or replaced. Its history entry is kept, but the extension will not offer to reveal a missing file.

Helper & manual updates

The matching helper version is 0.2.2. Component check results are available in the extension’s connection details.

New installers are supplied by the beta maintainer with each release. To update the helper, quit Chrome and run the new .pkg. Copy the new extension files over the folder originally loaded into Chrome, open chrome://extensions, reload VideoPocket and reconnect. The extension and helper must both be compatible with 0.2.2. Updates do not remove videos or recent tasks. Thumbnail generation requires the new 0.2.2 helper. Older records are kept without retroactive thumbnails.

There is currently no public download URL. Use the installer from the same release as your extension. The maintainer must provide an accessible release URL before public distribution.

Uninstall

Remove VideoPocket at chrome://extensions. Quit Chrome, then run 卸载拾影助手.app from the release archive and follow its prompts.

The uninstaller removes the helper and Chrome registration, keeping all videos and local records. To remove history, first use “Clear history” in the extension, or use Finder’s “Go to Folder” to open ~/Library/Application Support/VideoPocket and delete that folder.

Local storage & privacy

No account or video relay server is used. The current URL is read only when you open the extension or select “Use current page”. The extension does not read cookies or continuously monitor browsing. The last 20 tasks, save folder and redacted errors are stored locally.

Your Mac connects directly to the video site and its media services, with the source page’s referrer when needed. The selected media URL and referrer are stored locally with the task and may contain temporary access parameters. Only download content you own or have permission to save.
