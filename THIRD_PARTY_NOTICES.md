## Before redistributing a binary build

The current fetch script uses yt-dlp_macos.zip (a packaged distribution), not just the Unlicense-only source tree. Treat the exact bundled dependencies as part of your redistribution review. A copy of yt-dlp source alone does not necessarily satisfy all corresponding-source obligations for the packaged executable.

Record the exact component versions, hashes, licenses, notices, changes and build configuration. Provide the applicable license texts and corresponding source, including required dependency source/build material, using a delivery method that satisfies each license. Upstream project links or a README disclaimer alone are not a completed redistribution review. Independent-process invocation does not remove redistribution duties for binaries included in an installer.

The local build script copies available upstream notices and some source archives. This is preparation, not a determination that the generated installer fulfills every obligation. No prebuilt installer is published with this source release. Codec patents and platform/content permissions are separate questions; this notice does not clear them.
